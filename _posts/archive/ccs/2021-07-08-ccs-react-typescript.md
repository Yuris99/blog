# React에 Typescript 적용해서 생성하기

React를 가장 쉽고 빠르게 구축할 수 있는 CRA를 이용해서 Typescript React를 구축해보겠습니다.

터미널을 여시고, 

```
npx create-react-app [appName] --template=typescript
```
